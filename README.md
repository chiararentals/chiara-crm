# Chiara CRM

Interni CRM tracker za Chiara Apartments & Villas (React + Vite + Tailwind).

**Trenutna faza: A – radi lokalno s testnim podacima** (podaci se spremaju samo u pregledniku).

## Pokretanje na računalu
1. Instaliraj Node.js (LTS) s https://nodejs.org
2. U mapi projekta: `npm install`, zatim `npm run dev`
3. Otvori adresu koju ispiše (obično http://localhost:5173)

Plan i struktura baze: `docs/PLAN.md`
